🔧 Service Worker Debug Tool

Use this tool to diagnose why your extension service worker isn't running.

Step 1: Check Extension Status

  1. Open chrome://extensions in a new tab
  2. Enable Developer mode (toggle top-right)
  3. Find your AITestGen extension
  4. Check if extension is enabled (toggle should be ON/blue)

Step 2: Check Service Worker Status

  1. In chrome://extensions, find your extension
  2. Look for "service worker" link (or "background page")
  3. Click it to open the service worker console
  4. Check what it shows:
    • "running" ✅ - Service worker is active
    • "inactive" ❌ - Service worker is not running
    • Error messages ❌ - There's a problem

Step 3: Check Service Worker Console

After clicking "service worker", check the console for:

  • ✅ background loaded - Service worker started successfully
  • ❌ Red error messages - These indicate what's wrong
  • ❌ Import/module errors - Build or dependency issues
  • ❌ Syntax errors - Code issues

🔴 Common Service Worker Issues & Fixes

Issue 1: Service Worker Shows "Inactive"

Fix:

  1. Click the 🔄 Reload button on the extension
  2. Wait for reload to complete
  3. Click "service worker" again
  4. It should now show "running"

Issue 2: Errors in Service Worker Console

Common errors and fixes:

  • "Failed to load service worker"
    • Check if dist/background.iife.js exists
    • Rebuild: pnpm -F chrome-extension build
    • Reload extension
  • "Uncaught SyntaxError"
    • There's a syntax error in the code
    • Check TypeScript: pnpm -F chrome-extension type-check
    • Fix errors and rebuild
  • "Failed to import module"
    • Missing dependency or import issue
    • Check build output for errors
    • Reinstall dependencies: pnpm install
  • "chrome.runtime is undefined"
    • Extension context invalidated (extension was reloaded)
    • Reload the extension again

Issue 3: Service Worker Keeps Going Inactive

Possible causes:

  • Service worker crashes due to an error
  • Check console for recurring errors
  • Look for infinite loops or memory issues
  • Try restarting Chrome completely

Step 4: Force Service Worker to Start

If service worker is inactive, try these steps:

  1. Reload the extension (🔄 button in chrome://extensions)
  2. Send a message to wake it up: 
    // Run this in the service worker console or web page console
chrome.runtime.sendMessage('YOUR_EXTENSION_ID', { action: 'ping' }, (response) => {
  console.log('Response:', response);
  console.log('Error:', chrome.runtime.lastError);
});
  3. Check if it responds - If it does, service worker is now active

⚠️ Important Notes

  • Service workers go inactive when Chrome thinks they're not needed
  • After building, you MUST reload the extension
  • Service workers can't be woken up by external messages if they're inactive
  • You must manually reload the extension in chrome://extensions
  • Check the console for errors - they prevent the service worker from starting

Step 5: Verify Service Worker is Running

Once you've fixed the issues:

  1. Go to chrome://extensions
  2. Click "service worker" link
  3. Verify it shows "running"
  4. Check console for background loaded
  5. Go to debug-extension.html and test connection

Quick Checklist

  • Extension is enabled in chrome://extensions
  • Extension was reloaded after last build
  • Service worker shows "running" (not "inactive")
  • Service worker console shows "background loaded"
  • No errors in service worker console
  • Extension ID is correct
  • Web app is at http://localhost:3000 (not file://)
