🔍 Extension ID Helper

This tool helps you find the correct extension ID for your unpacked extension.

Step 1: Open Chrome Extensions Page

1. Open a new tab in Chrome

2. Go to: chrome://extensions

3. Enable Developer mode (toggle in top-right corner)

Step 2: Find Your Extension

1. Look for "AITestGen" or "__MSG_app_metadata_name__" in the list

2. Find the ID shown directly under the extension name

3. It looks like: abcdefghijklmnopqrstuvwxyz123456

⚠️ Important: For unpacked extensions, this ID is different from the published extension ID!

Step 4: Reload the Extension

⚠️ CRITICAL: After building, you MUST reload the extension!

  1. In chrome://extensions, find your AITestGen extension
  2. Click the 🔄 Reload button (circular arrow icon)
  3. Wait for it to reload
  4. Click the "service worker" link (or "background page")
  5. Verify it shows "running" (not "inactive")
  6. Check the console for errors - you should see: background loaded

Step 5: Test Connection

Once you have the extension ID and have reloaded the extension:

  1. Go to: http://localhost:3000/debug-extension.html
  2. Enter the extension ID
  3. Click "Test Connection"

⚠️ Common Issues

  • Service worker inactive: Reload the extension and check the service worker console
  • Wrong extension ID: Make sure you're using the ID from chrome://extensions, not a published ID
  • Extension not enabled: Make sure the toggle is ON (blue/enabled)
  • Extension not reloaded after build: Always reload after running pnpm -F chrome-extension build
  • Wrong origin: Make sure web app is at http://localhost:3000 (not file://)
